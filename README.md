# DocVault

**we are here to remember**

DocVault is a privacy-first document expiry reminder. Document name, type and expiry date are stored only in the browser's localStorage. The server does not store a shared vault.

## Run locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Render
Build command: `pip install -r requirements.txt`
Start command: `python app.py`

## Important
Clearing browser/site data can erase the local vault. Use Export Backup before changing devices or clearing browser data. Do not enter CNIC/passport numbers or upload document photos in this first version.
